# opotopo/seller-api-bitrix

Модуль 1С-Битрикс `masstech.opotopo`: выгрузка каталога интернет-магазина на площадку ОПОТОПО через Seller API — товары, торговые предложения и остатки при изменении и по расписанию; заказы площадки — заказами сайта с исполнением из формы заказа.

Установка — архив `masstech.opotopo.zip` последнего выпуска в каталог `local/modules` сайта, затем «Marketplace» → «Установленные решения» → «Установить».

Руководство — https://opotopo.com/knowledge/developers/klient-dlya-1s-bitriks
